# AgentConfigScore v0.26.2

This **Beta** patch delivers the bounded path-reference maintenance changes
previously available only in the source checkout.

```bash
python -m pip install --upgrade agent-config-score==0.26.2
agent-config-score --version
```

Expected version: `AgentConfigScore 0.26.2`. GitHub Action users can pin
`LE0-Lin/AgentConfigScore@v0.26.2`; the rolling `v0` branch follows the verified
release commit.

## Path behavior

- A complete, immediate generated-output declaration exempts only that output
  prose reference from an existence warning. Generator paths, actual Markdown
  links, commands and credentials remain checked. The declaration is not
  authenticated and no build is run.
- Single-backtick directory references require both an explicit `./` or `../`
  prefix and a trailing `/`. A regular file cannot satisfy them; directory
  matching does not use an ambiguous suffix fallback. Unprefixed directory
  prose remains unresolved, including package/install/build outputs.
- Existing ordinary file-reference behavior, baseline-owned policies and
  explicit unknowns remain in place. See the [full path contract](../limitations.md#plain-prose-path-references).

## Validation and upgrade impact

The release replays the actual built wheel before publication. Source tests,
installed acceptance on Linux/Windows/macOS, Cursor Action acceptance, deletion
approval demo and Linux path-development replay gate the release. Version and
source fingerprints identify the installed implementation.

Directory warnings can change when instruction files explicitly opt into the
supported relative spelling. Review affected CI findings after upgrading; a
clean result is not semantic correctness or agent-safety certification.

The [public-source case](../path-case-study.md) and [retained observations](../../benchmarks/path-check-v2/README.md)
document the generated-output fix, intermediate regressions, final conservative
scope and separate explicit-directory controls. Historical artifacts keep their
original version/source identities. A release is not a new independent accuracy
study, external adoption result or runtime agent-enforcement capability.
