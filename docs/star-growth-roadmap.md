# AgentConfigScore Growth Roadmap

## Goal

Make AgentConfigScore a practical tool for improving AI coding-agent instruction quality.

## Current improvements

- Score history tracking
- CI integration
- Regression detection
- HTML and badge reports
- Visual demo gallery for regression checks, setup, and score history
- Branded GitHub social preview for recognizable link sharing

## Next priorities

### User experience

- Add simple history CLI output
- Improve explanations for findings
- Add more examples for popular AI coding tools
- Keep the score contract and known limitations visible wherever A 100 is shown

### Community growth

- Turn visual demos into short launch clips for community posts
- Add templates users can copy
- Publish usage examples
- Collect sanitized real-world hits, false positives, and false negatives through the issue form

### Engineering quality

- Increase test coverage
- Keep APIs stable
- Improve contributor documentation
- Expand the adversarial corpus before expanding the rule catalog
