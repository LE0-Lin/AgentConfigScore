# 分數意義與限制

[English](../limitations.md) | [简体中文](../simplified/limitations.md) | 繁體中文 · [使用指南](user-guide.md)

AgentConfigScore 是確定性靜態檢查器與回歸門禁。分數只反映固定規則目錄的命中情況，不衡量模型能力、任務成功率或指令整體品質。

**A 100 表示沒有命中生效規則，不是語意品質或安全認證。**

全工具共有的基本邊界：

- **純本機靜態分析**：不呼叫 AI 模型、不存取網路，也不執行指令檔中的任何命令。
- **不是檔案系統沙箱**：路徑、設定與符號連結檢查適用於穩定的本機工作目錄，不針對並行寫入或惡意檔案系統提供原子交易保證。
- **來源指紋**：報告附帶工具版本與原始碼 SHA-256 指紋（[報告身分（英文）](../report-identity.md)），用來識別建置版本，不代表準確率認證。

## 哪些問題仍可能得 A 100

只要避開已啟用的規則，下列情況仍可能得到 100 分：

- 空泛、沒有實際幫助但非空白的指令（如 `"Do a good job."`）。
- 未使用已收錄危險命令或固定句式表達的有害意圖。
- 經過改寫、措辭不完全一致的指令矛盾。
- 規則目錄以外的破壞性工具或 shell 寫法。
- 語法無誤但與實際儲存庫不符的指導。

我們不靠容易刷分的「最佳實務關鍵字」加分。更廣義的語意評審應放在獨立評測的模型輔助流程中。此外，中文文件只是選用的閱讀入口，**不代表工具能理解任意中文語意**。

## 設定、歷史與檔案系統邊界

- **嚴格 JSON 設定**：`.agentconfigscore.json` 拒絕任意層級的重複鍵名、`NaN`/`Infinity` 以及布林型別 `version`，且必須解析為儲存庫根目錄內的一般檔案。損壞、失效連結或越界設定直接回傳退出碼 `2`（`doctor` 回傳 `1`），不會悄悄回退到預設值（[設定解析（英文）](../doctor.md#configuration-decoding)）。
- **本機歷史索引**：歷史檔案損壞或無法讀取時，`history` 回傳 `2` 而不會清空重設；附加寫入採用整檔替換，要求循序呼叫（[本機歷史（英文）](../score-history-cli.md)）。
- **指令檔邊界**：選取的指令檔與 `.agentconfigscoreignore` 必須是儲存庫內的一般檔案（支援儲存庫內檔案符號連結，但不進入子目錄符號連結或 Windows junction）。失效、循環、越界或無法讀取的來源會直接中止掃描並回傳 `2`（`doctor` 報 `instructions` 錯誤並回傳 `1`），不回顯原始目標路徑；舊規則 `read-error` 僅為歷史相容保留。

## 命令與禁止上下文

`rm-rf`、`git-clean-force`、`docker-system-prune` 會對受限長度（1,000 字元內）的 shell 片段做選項解析，支援重排、拆分、長選項、引號值與反斜線續行，並在分隔符號或 `--` 處停止。Git 預覽/互動模式、`rm` 後續互動選項以及過濾參數值不會誤判；運算元之後的選項、變數展開、別名與包裝函式不解析。

明確標示的禁止語句可涵蓋緊鄰的閉合程式碼區塊或連續命令清單；未標示區塊、未閉合區塊不會自動豁免，認證資訊規則始終獨立生效（[指令上下文（英文）](../instruction-context.md)）。

## 提示注入與敘述安全規則

- **`prompt-injection-override`**：識別 `ignore previous instructions` 等明確英文覆寫片語。明確禁止、整行標示範例與緊鄰禁止區塊可排除，但純引號或程式碼圍欄不自動豁免；任意改寫、其他語言及執行時工具輸出注入不在涵蓋範圍內（[英文詳細邊界](../limitations.md#prompt-injection-warnings)）。
- **`false-success-report`**：涵蓋單句英文隱瞞錯誤回報成功，以及英文與有限簡體／繁體中文的「測試失敗或未執行仍宣稱通過」句式；不跨句拼接，也不檢查測試是否真的執行（[規則細節（英文）](../verification-reporting.md)）。
- **`deletion-approval-bypass`**：涵蓋英文與有限中文中同時包含「刪除生產資料庫或既有/使用者檔案」與「免授權」的明確句式；正常授權、暫存清理、禁止語句與範例分開處理（[規則細節（英文）](../deletion-approval-bypass.md)）。
- **`broad-environment-upload`**：要求同一英文子句同時出現傳輸動作、完整環境變數來源與非回環網路目標；僅列變數名、移除敏感資訊、日誌、禁止句與程式碼範例不觸發（[規則細節（英文）](../environment-upload.md)）。

## 本機 Markdown 連結與敘述路徑

- **Markdown 連結**：檢查行內連結、圖片，以及同檔單行定義的簡單參照式連結（`[指南][setup]`、`[setup][]`），依指令檔所在目錄解析。略過遠端連結、純錨點、程式碼區塊、相符的行內程式碼、跳脫左括號、絕對路徑與越界路徑；簡寫參照、跨行定義、容器內定義、巢狀括號與 HTML 排版需人工核對（[英文詳細邊界](../limitations.md#local-markdown-links)）。
- **明確相對路徑（`./`、`../`）**：依儲存庫根目錄及適用的指令作用域目錄核對，不走無關套件後綴兜底。帶 `./` 或 `../` 且以 `/` 結尾的單反引號目錄引用要求目標為真實目錄；無前綴的 `packages/`、`dist/`、`test/unit` 不做猜測。
- **無前綴檔案路徑**：使用保守的套件相對後綴索引（包含 `build`、`dist`、`target`、`.next` 中已存在的檔案，但略過相依套件/管理目錄與目錄符號連結）。建立索引遇到目錄遍歷錯誤時直接回傳 `2`，不會用不完整索引繼續掃描。
- **窄範圍非必需豁免**：緊鄰的 `(if exists)` / `(if it exists)`、同行的被動產生宣告（如 `` `docs/out.json` is generated by `make docs` ``），以及明確儲存庫角色中的 `owner/tool.js` 兩段名稱只豁免對應敘述路徑；實際的 Markdown 連結、產生器路徑、危險命令與認證資訊不受影響（[英文詳細邊界](../limitations.md#plain-prose-path-references)）。

## Cursor 上下文、回歸門禁與輔助命令

- **Cursor `scope` / `coverage`**：靜態預測根目錄 `.cursor/rules/` 的自動載入情況；手動/模型選擇規則與不支援的正文保持 `unknown`，不觀察 Cursor 實際執行（[cursor-scope](../cursor-scope.md)、[cursor-coverage](../cursor-coverage.md)）。
- **回歸門禁**：缺少指令檔（`no-config`）、空白檔案（`empty-instructions`）及任意生效錯誤都會把等級限制在 A 以下。`instruction-file-removed` 僅豁免同目錄內一對一、原文完全一致的新增檔案搬移；`directive-polarity-flip` 與 `contradiction` 僅比對精確指令正文（[回歸涵蓋範圍（英文）](../regression-coverage.md)）。兩側同為 100 分時，需開啟 `fail_on_new_errors` 才會阻擋回歸專用錯誤。
- **`--explain`、`init` 與 `guardrails`**：`--explain` 只補充靜態建議，不自動修改檔案；`init --pr-comment` 明確申請 `pull-requests: write`，預設 `init` 保持唯讀；`guardrails` 為單檔不計分檢查，追加寫入需明確確認權杖（[維護者流程（英文）](../maintainer-workflow.md)、[刪除保護（英文）](../guardrail-suggestions.md)）。

## 評測邊界

- **離線對抗案例集**：474/474 項確定性契約全部相符，8 項公開挑戰偵測到 6/8（剩餘 2 項為語意漏報）。這是封閉回歸集，不代表真實儲存庫準確率。
- **AI 對比評測**：目前尚未完成具獨立人工仲裁標籤的留出集對比（[評測方法（英文）](../review-comparison.md)）。

## 適用方式

把 AgentConfigScore 用作穩定的確定性回歸門禁與例外稽核工具，而不是產出程式碼、儲存庫安全或指令品質的唯一核准依據。[翻譯範圍與維護說明](../translations.md)。
